## DNS設定の変更後に手動再起動が不要になりました

約30秒ごとに現在のルーター設定を確認し、`dns server`、`dns server select`、`dns host`、簡易DNS登録、必要なインターフェースのIPv4設定などの変更を自動反映します。PP・DHCPで取得するDNSアドレスの更新も引き続き確認します。

変更がなければ接続とキャッシュを保持します。変更時は古い接続とキャッシュを破棄し、同じLuaタスク内で初期化し直します。設定反映中の問い合わせが一時的に失敗する場合があります。DNSを無効にした場合や設定を読み取れない場合は待受を停止し、有効な設定に戻れば自動で復帰します。[自動再読込の詳しい動作](../config-reload.md)

v0.9.9の共通機種対応、PP・DHCPからのDNS取得、IPv6のみの上流を使えない場合のIPv4選択、送信元ごとの制限、大きなTCP応答、256件キャッシュを引き継ぎます。
