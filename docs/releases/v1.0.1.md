# v1.0.1 — PP・DHCPの状態解析とDNS選択を修正

ソースコード・テスト・ドキュメントはすべてOpenAI Codexで生成した。

**公開前のRelease本文案です。**

- 英語・日本語のPP状態表示を見直し、接続中のPPを認識できずSERVFAILとなる問題を修正しました。
- PPの接続条件とDHCPのDNS取得状態に応じた選択を、内蔵DNSの実測に合わせました。
- PP接続中に通知DNSがなく、保持中の代替DNSを特定できない場合は通常の固定DNSを使用し、EDNS対応クライアントへEDE注記を返します。

RTX830・RTX1210で機能・回帰試験を行い、RTX830では制限を緩めた限界負荷試験と試験後の復帰を確認しました。設定の自動再読込や既存の利用制限も維持しています。
