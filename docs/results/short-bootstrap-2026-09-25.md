# 短縮インストールコマンドの検証

ソースコード・テスト・ドキュメントはすべてOpenAI Codexで生成した。

2026年9月25日、コピペするコマンドを1,102文字から395文字（`yes`指定時）へ短縮しました。固定commitから取得したインストーラーをメモリ上で実行します。取得時のHTTP・サイズ確認はコマンドに残し、指定した版との一致、重複起動の検出、保存先の準備、本体の検証・差し替え・復旧はインストーラー側で行います。

## ホスト試験

Makefileに記載された全試験コマンドを実行し、成功しました。インストーラーのLua試験674 assertions、HTTP取得149 assertions、SHA256 25 assertions、Python全36件（インストーラー関連19件）を含みます。

| 確認項目 | 結果 |
|---|---|
| 取得・実行 | HTTP失敗、取得サイズ不一致、構文エラーを拒否。コマンド側からファイル書き込み、ルーターコマンド、グローバル`arg`の変更を行わないことを確認。 |
| 版の固定 | 同じサイズの別バージョンも、インストーラーの処理を開始する前に拒否。新しい呼び出し方式に未対応の旧インストーラーからは、短縮コマンドを生成しない。 |
| メモリ実行と手動転送 | 開始引数と指定版の受け渡し、従来の`lua /lua/rtx-dns-install.lua yes`形式を確認。メモリ実行では既存のインストーラーファイルを上書き・削除しない。 |
| 保存先 | `/lua`がなければ作成。保存先を利用できない場合は、稼働中のDNSを停止する前に失敗する。 |
| 既存処理 | 重複起動の拒否、SHA256照合、起動失敗時の復旧、Scheduleと設定保存の回帰試験に成功。 |
