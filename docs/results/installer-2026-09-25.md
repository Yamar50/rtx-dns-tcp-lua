# 安定版インストーラーの検証

[インストールと機能](../../README.md) · [技術資料一覧](../README.md)

ソースコード・テスト・ドキュメントはすべてOpenAI Codexで生成した。

このページは、従来の最新安定版を自動選択するインストーラーの検証記録です。現在の配布方法はバージョン別へ変更しました。[バージョン別インストーラーの試験記録](versioned-installer-2026-09-25.md)を参照してください。以下の結果は、当時の実装と試験対象を記録したものです。

2026年9月25日に、RTX1210 Rev.14.01.42（Lua 5.1.5、Luaスクリプト機能1.08）で検証しました。取得対象は、この時点の最新安定版v0.1.4です。Pre-releaseのv0.9.9は選択しません。

| 確認項目 | 結果 |
|---|---|
| コマンド1行による導入 | 公開したcommitのHTTPS URLからインストーラー自身を取得し、最終完了まで成功。 |
| Latestの選択とHTTPS取得 | v0.1.4を選択し、Releaseと同じ143,094バイトを取得。 |
| SHA256 | 標準ベクトルと本体ファイルで一致。組み込みbit演算を利用した本体の照合は約33秒。 |
| 新規インストール | 本体が存在しない状態から書き込み・起動・作業ファイル削除に成功。 |
| 既存版からの更新 | 稼働中の対象を停止し、検証済みファイルへ置き換えて起動。 |
| 同じ内容での再実行 | 本体の上書きを省略し、対象タスクを再起動。 |
| SHA256不一致 | 停止・置換を行わず終了。既存ファイルと既存タスクの開始時刻を維持。 |
| 起動失敗 | 起動できない状態を試験用に挿入し、旧ファイルと実行状態の復元を確認。 |
| 自動起動の登録 | 既存番号と衝突しない番号を選択し、設定ファイルへの保存を確認。 |
| 自己削除 | 成功時に実行中のインストーラー自身と作業ファイルを削除。 |
| 導入後のDNS | TCPのA・AAAA・ローカル名、大きなTXTのUDPからTCPへのフォールバックが正常。 |

自動起動の保存試験では、保存先だけを未使用のCONFIG1へ差し替え、起動用configを変更せずに`save`の実行と保存内容を確認しました。試験で追加した設定とCONFIG1は削除して元に戻しています。起動失敗試験では、起動要求の成功応答だけを返し、実際のタスクを起動しない状態を注入しています。

ホスト側では、インストーラーのLua試験621 assertions（SHA256 25、HTTP 179、更新処理417）と、bootstrapの7シナリオを確認しました。HTTPS以外への転送、転送ループ、破損したmanifest、サイズ超過、同時実行、途中でのconfig変更、書き込み失敗、起動失敗、スケジュール設定の部分的成功、保存結果が不明な場合などを含みます。既存DNS本体の回帰試験も成功しています。

インストーラーはDNS本体と独立しています。本体の通信処理・制限値・Releaseの配布ファイルを変更するものではありません。この実機確認はRTX1210で行っており、他機種でのインストーラー実行結果は今後の報告をお待ちしています。
